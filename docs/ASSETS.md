# App icon

The app icon uses a navy tile, a pale document, and a teal/blue magnifying glass.
It was created with the built-in imagegen tool and checked for transparency and small-size readability.

The 1024-pixel master is
`Apps/LocalSeek/Assets.xcassets/AppIcon.appiconset/icon_512x512@2x.png`.
The asset catalog includes all ten standard macOS icon representations from 16 to
1024 pixels, derived with macOS `sips`. Xcode compiles them into the app's icon resources.
The README references the same master rather than maintaining a second logo.

## Generation prompt

Use case: logo-brand. Asset type: production macOS app icon for LocalSeek, an on-device document search app. Create a single finished square 1024x1024 icon, front-on, centered. A deep navy rounded-square tile with restrained soft depth; on it, a pale document with a folded corner and a bold teal-to-blue magnifying glass over the lower right of the document. The visual idea is finding local files. Polished native macOS app-icon styling, crisp silhouette, generous internal spacing, high contrast, recognizable at 16px, subtle material lighting rather than ornate detail. Use navy, pale blue-white, and mint/teal with a small cobalt accent. Tile occupies about 88% of the canvas with equal padding. Outside the rounded-square tile must be genuinely transparent, with no colored backdrop or mockup scene. No text, letters, checkmarks, badges, extra objects, watermark, or Apple logo.
