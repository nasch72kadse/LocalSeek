## Search and indexing improvements

- Search results count distinct documents, so a long document cannot hide other
  matching files by filling the candidate list with its own text passages.
- Changes in separate folders stay scoped to those folders. Cross-folder renames
  retain existing file IDs and embeddings.
- Large metadata scans yield between small batches so other sources can progress.
- PDFs save completed pages and resume after interruption or an app restart. Previous
  successful content remains searchable until the replacement is complete.
- Status updates run asynchronously and reuse unchanged favorite lists.
- Semantic search can use acceleration with filters, expanding candidates and falling
  back to exact search when necessary.
- Superseded filename searches cancel their own database work.

The database upgrade adds PDF checkpoints and favorite revision tracking. No manual
index rebuild is required. Search acceleration remains approximate; indexing batches
cannot interrupt a parser or OCR call already in progress.
